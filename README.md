# ITGD Lab 1 – City Block

A 2D Godot 4 project showing a small city scene with a school
and three tall buildings.

## Structure
- main_scene.tscn – the main scene (root node: Main)
- tall_building.tscn – reusable scene with a Sprite2D of a tall building
- school.tscn – reusable scene with a Sprite2D of a school
- The main scene has 3 instances of tall_building and 1 instance of school

## What I learned
- I learned how to properly use Godot for the first time.
- Understanding how to build a 2D world to then move onto 3D models.
- Adding a node while another node is selected and puts it within that node, so I had to move TallBuilding back under Main.
